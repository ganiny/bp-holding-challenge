# Project Brief

BP Holding Website Summary Requirements

## Project Goal

Build a premium bilingual digital platform for Business Pioneers Holding (BP Holding) that positions the company as a leading Saudi construction and engineering firm while supporting recruitment, contractor onboarding, RFQ generation, internal HR operations, community management, lead generation, e-commerce, and portfolio showcase.

## Business Focus

- Residential Construction
- Structural / Concrete Works
- Interior Finishing & Interior Design
- Engineering Consultations
- General Contracting

## Core Objectives

- Present BP Holding professionally online
- Generate leads / RFQs from clients
- Accept contractor/supplier applications
- Accept job applications
- Provide downloadable company profile/catalog
- Build trust through certifications and legal compliance
- Support digital sales / payments for products & services
- Provide internal employee/HR management portal
- Build PEG-N & Business Pioneers digital communities(PEG-N is short for Professional Engineers Global Network)
- Create a scalable ecosystem for future business expansion

- Only admins can log in to admin dashboard

- Employees can log in to employee portal only

Public Users:

## User Flows

RFQ Flow:

- Visitor → RFQ Page → Fill Form → Upload Files → Submit → Admin Dashboard

Job Application Flow:

- Visitor → Careers Page → Select Job → Apply Form → Upload CV → Submit → Admin Dashboard

Contractor Registration Flow:

- Visitor → Contractor Page → Fill Company Form → Upload Docs → Submit → Admin Dashboard

Portfolio Management Flow:

- Admin → Dashboard → Add/Edit Project → Upload Images/Videos → Publish

Store Purchase Flow:

- Visitor → Browse Store → Add to Cart → Checkout → Select Payment Method → Pay / Generate Invoice

Employee Portal Flow:

- Employee Login → Dashboard → Upload Docs / Submit Request → HR Review

PEG-N Registration Flow(PEG-N is short for Professional Engineers Global Network):

- Visitor → PEG-N Page → Register → Upload Portfolio → Admin Review / Lead Assignment

Community Opportunity Flow:

- Member → Browse Opportunity → Submit Offer / Proposal → Admin/Poster Review

## Description

Build a premium bilingual corporate website for Business Pioneers Holding (BP Holding), a Saudi construction and engineering company specializing in residential construction, structural concrete works, interior finishing, interior design, and engineering consultation. The website should position the company as a high-end, trustworthy contractor in the Saudi market while supporting lead generation, RFQ submissions, contractor onboarding, job applications, and admin content management. The platform must include a custom admin dashboard for managing projects, applications, inquiries, and dynamic website content.
